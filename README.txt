# 진중교회 홈페이지 — 사용 안내

이 폴더를 통째로 인터넷에 올리면 교회 홈페이지가 됩니다.
(Netlify 등 무료 정적 호스팅에 폴더째 올리면 됩니다.)

## 페이지 구성
- index.html      : 홈 (첫화면·소그룹/가정예배·설교/찬양·예배시간·교회소개·오시는길)
- history.html    : 교회 역사 (1964~ 연혁 타임라인)
- bylaws.html     : 교회 정관 (6장 51조 전문)
- bulletin.html   : 주보 (블로그 최신 주보 연결)
- board.html      : 게시판 (설교·찬양·소그룹·가정예배·자료실) — 노션 연동 예정
- img/            : 로고(흰색/컬러), 교회 사진(첨탑·드론)
- 가정예배지_*    : 가정예배지 자료

## 로고
- logo-white.png : 흰 글자 (어두운 배경용, 첫화면 상단·푸터)
- logo-color.png : 컬러 글자 (흰 배경용, 스크롤 후 상단)
- 첫 화면에서 스크롤하면 흰색→컬러 로고로 자동 전환됩니다.

## 첫 화면
- 배경: 첨탑 사진(img/steeple.jpg), 가운데 "용서, 사랑의 시작입니다" 표어
- 버튼: 설교 보기

## 메뉴
소개(교회소개·교회역사) / 설교 / 찬양 / 소그룹 / 가정예배 / 주보 / 자료실 / 정관 / 오시는길

## 게시판 (board.html) — 노션 연동
현재는 "아직 등록된 글이 없습니다"가 표시됩니다.
노션 연동(빌드 스크립트)을 붙이면 board-data.json 이 생성되어
설교·찬양·소그룹·가정예배·자료실 글이 자동으로 채워집니다.
- 노션 DB ID: 378caa6ab69380bea0c1ffcfbdced89d
- 노션 토큰: Netlify 환경변수에 직접 등록 (코드/파일에 넣지 않음)
