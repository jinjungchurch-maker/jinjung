# 게시판 연동 + 배포 안내서

진중교회 홈페이지의 게시판(설교·찬양·구역모임·가정예배·주보)을
노션과 연결해서 자동으로 채우는 방법입니다.

────────────────────────────────────
## 작동 원리 (간단히)
────────────────────────────────────
1. 목사님이 노션에 글을 올립니다 (제목·카테고리·날짜·첨부·체크박스).
2. "공개(체크박스)"를 켠 글만 홈페이지에 나옵니다.
3. 배포(또는 다시 배포)하면, build-board.js 가 노션을 읽어
   board-data.json 파일을 만듭니다.
4. 게시판 페이지(board.html)가 그 파일을 읽어 글 목록을 보여줍니다.

→ 토큰(열쇠)은 코드에 적지 않고, 배포 사이트의 "환경변수"에 넣습니다.
  (그래야 방문자에게 토큰이 노출되지 않습니다. 안전합니다.)

────────────────────────────────────
## 준비물 (이미 다 있음)
────────────────────────────────────
- 노션 토큰        : 2단계에서 만든 "API 통합 토큰" (ntn_... 으로 시작)
- 데이터베이스 ID  : 378caa6ab69380bea0c1ffcfbdced89d
- 폴더 안 파일      : build-board.js, package.json, netlify.toml, board.html 등

────────────────────────────────────
## 배포 방법 A — Netlify (자료 많고 쉬움)
────────────────────────────────────
1. github.com 가입 → 새 저장소(repository) 만들기
   (또는 Netlify에 폴더를 끌어다 놓아도 되지만, 빌드를 쓰려면 Git 연결이 편함)
2. 이 폴더의 모든 파일을 저장소에 올림
3. netlify.com 가입 → "Add new site" → "Import an existing project"
   → 방금 만든 GitHub 저장소 선택
4. 빌드 설정은 netlify.toml 에 이미 있으니 그대로 둠
   (Build command: node build-board.js / Publish: .)
5. "Environment variables"(환경변수)에서 두 개 입력:
     NOTION_TOKEN       = (노션 토큰 붙여넣기)
     NOTION_DATABASE_ID = 378caa6ab69380bea0c1ffcfbdced89d
6. "Deploy"(배포) 클릭 → 잠시 후 사이트 주소가 나옴
7. 사이트 이름을 jinjung 등으로 변경 → jinjung.netlify.app

매주 갱신: 노션에 새 글 올린 뒤 → Netlify에서 "Trigger deploy"(다시 배포) 클릭
(또는 자동 배포를 설정하면 주기적으로 갱신)

────────────────────────────────────
## 배포 방법 B — OnPod (한국 서비스, onpod.ai)
────────────────────────────────────
OnPod은 한국어·원화 결제가 되는 신생 배포 서비스입니다.
화면 구성이 자주 바뀔 수 있으니, 아래 "공통 개념"으로 찾으세요.
1. onpod.ai 가입 → 새 프로젝트/배포 만들기
2. 이 폴더(또는 GitHub 저장소)를 연결
3. 빌드 명령(Build command)에 입력:  node build-board.js
4. 환경변수(Environment variables)에 입력:
     NOTION_TOKEN       = (노션 토큰)
     NOTION_DATABASE_ID = 378caa6ab69380bea0c1ffcfbdced89d
5. 배포 실행 → 주소 발급
※ 화면 위치를 모르겠으면 OnPod 고객지원에
   "정적 사이트 + Node 빌드 + 환경변수 설정 방법"을 문의하세요.

────────────────────────────────────
## 노션 글 작성 요령
────────────────────────────────────
- 제목      : 글 제목 (예: "내 증인이 되리라")
- 카테고리  : 설교 / 찬양 / 구역모임 / 가정예배 / 주보 중 선택
- 날짜      : 주일 날짜
- 파일과 미디어(첨부) : PDF·이미지 올리기 (누르면 그 파일로 연결됨)
- 체크박스(공개) : ✅ 켜야 홈페이지에 보임 (작성 중이면 끄기)
